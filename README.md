# 房間佈置模擬器

寫實風格的 3D 房間佈置模擬器。純靜態網站（HTML、CSS、JavaScript、Three.js），不需要後端，也不需要建置步驟。

## 開啟方式

- **GitHub Pages**：在 repo 的 Settings → Pages 選「Deploy from a branch」，分支選 `fable-dev`、資料夾選 `/ (root)`。
- **分支預覽**：`https://raw.githack.com/wuserena/bedroom-studio/fable-dev/index.html`
- **本機**：在專案資料夾執行 `npm start`，再開 `http://localhost:4173`。（直接雙擊 `index.html` 不行，瀏覽器會擋下本機的 JavaScript 模組。）

## 功能

- 視角：全景、俯視、室內、門口、床上。拖曳空白處旋轉，滾輪或雙指縮放。
- 家具：點選、拖曳移動、旋轉（15°／90°）、複製、刪除，選取時顯示尺寸與占地範圍。
- 碰撞：家具不能穿過牆、入口牆面、柱子、固定木作、開門扇形與其他家具；被擋住時停在最後一個合法位置並以紅色提示。
- 特殊規則：地毯可被家具疊放；洞洞板與鏡子掛在牆面，不可蓋住窗戶；娃娃與抱枕放在床面、桌面配件放在桌面，並跟著床或書桌一起移動旋轉。
- 照明：白天（窗外自然光）與晚上（三盞頂燈），頂燈與每一盞家具燈都可以獨立開關。
- 尺寸設定：房間、入口、柱子、天花板、窗戶、木作深度都可修改，3D 與碰撞立即更新。
- 資料：瀏覽器自動儲存、復原／重做、匯出與匯入 JSON、重設；缺少欄位的舊配置也能載入。
- 三個佈置提案：復古暖橘、無印日系、灰白北歐・金屬。

## 座標與尺寸（公分）

平面多邊形：`(0,0) (333,0) (333,293) (76,293) (76,313) (0,313)`

| 項目 | 數值 | 說明 |
|---|---|---|
| 大窗牆寬（x 方向） | 333 | `z = 0` 是大窗牆 |
| 房間深（z 方向） | 293 | `z = 293` 是門口牆，也是投影牆 |
| 入口凸出 | 76 × 20 | `z = 313` 是最外側，門在這面牆上 |
| 門 | 寬 76 | 鉸鏈在 `(0,313)`，往房內、朝大窗方向開 |
| 柱子 | 沿牆 44 × 突出 31.5 | `x 0–31.5`、`z 193–237`，在門全開範圍的前方 |
| 天花板 | 低 222／高 235 | 高天花板由大窗向內 115（估計） |
| 大窗 | 寬 223、高 108、窗台 93 | 高度為估計 |
| 小窗 | 寬 73、高 88、窗台 123 | 位於木作牆，窗台高為估計 |
| 固定木作 | 占地深 32 | 沿 `x = 333` 整面牆 |

## 測試

```bash
npm test
```

執行幾何與碰撞的單元測試。瀏覽器整合測試（需要 Playwright 與 Chromium）：

```bash
node tests/browser.mjs
```

## 檔案

- `index.html`、`css/style.css`：頁面與樣式
- `js/model.js`：房間幾何、家具目錄、碰撞、提案、資料遷移（不依賴 Three.js）
- `js/room3d.js`：房間、門窗、柱子、木作的 3D 模型
- `js/furniture3d.js`：家具 3D 模型
- `js/textures.js`：程序化材質
- `js/app.js`：場景、視角、互動與介面
- `vendor/`：Three.js r180（MIT 授權）
