# 房間工作室

線上使用：[開啟房間模擬器](https://wuserena.github.io/bedroom-studio/)

GitHub Pages 由 `.github/workflows/pages.yml` 自動部署。每次推送到 `main`，先執行測試及打包，再只發布 `dist/` 內的網站。原始照片和參考圖片保留在本機，不會推送到儲存庫。

本機版與網站版的瀏覽器儲存空間不同；搬移配置時，先從本機版匯出 JSON，再到網站匯入。

直接以 Chrome、Edge 或 Firefox 開啟 **room-simulator.html**。這個檔案已包含程式、3D 引擎與材質，不需要網路或安裝套件。需要支援 WebGL 2 的瀏覽器及硬體加速。

## 操作

- 左側選家具新增；在「立體全景」或「俯視配置」拖曳。
- 選取家具後可修改寬、深、高、顏色，或每次旋轉 15°。
- 「單人床」可選兩種款式：「預設」通用單人床，或 IKEA NORDLI 抽屜收納床（固定 120 × 202 × 30 cm，白色床架、側邊三抽）；NORDLI 可移動、旋轉、切換寢具方向，並分別更換棉被與枕頭顏色。
- 方向鍵移動 1 cm；Shift + 方向鍵移動 5 cm；R 旋轉；Delete 刪除；Ctrl / ⌘ Z 復原。
- 「室內視角」拖曳環看，滾輪縮放視野。此模式不拖動家具。
- 白天 / 夜晚切換，頂燈可獨立開關。
- 配置自動保存在同一個瀏覽器；「匯出配置」下載 JSON 備份，「匯入」重新載入。
- 「儲存畫面」下載目前 3D 畫面的 PNG。
- 「房間尺寸與結構」可校正估計值；若新房間與現有家具衝突，會拒絕套用。可以先移動或刪除相關家具。

家具碰撞採完整旋轉外框，包含把手等細節；快速拖曳沿路檢查，不會跳過障礙。固定櫃按整段深度占用空間，不能把椅子塞入桌下或把物件堆疊。門片示意開啟 45°，家具碰撞保留完整 90° 開門扇形。

## 開發與驗證

```sh
npm install
npm start
# 瀏覽 http://localhost:4173/room-simulator.html
npm test
npm run build
```

`index.html` 為原始開發頁（需要 npm install 後透過 HTTP 開啟）。`src/` 包含幾何與碰撞模型、3D 場景、介面及樣式。`npm run build` 產生單檔 `room-simulator.html` 和 `dist/index.html`。

瀏覽器驗證：啟動伺服器後執行 `node tests/interaction.mjs`；必要時以 `CHROMIUM_PATH` 指定 Chromium 路徑。`tests/browser.mjs` 產生日夜截圖至 `artifacts/`。單元測試涵蓋牆、柱、櫃、家具、旋轉、天花板、快速移動、匯入和外框擬合。

2026-10-13 校正：大窗牆方向為 333 cm、木作牆方向為 293 cm。舊版完全相同的預設房間會自動校正兩軸；使用者自行修改的尺寸保留。舊配置原文另存於瀏覽器 bedroom-studio-v1-before-entrance-fix，家具仍須通過新版碰撞檢查。
